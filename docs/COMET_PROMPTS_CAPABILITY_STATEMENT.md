# Comet Browser Assistant Prompts
## Rocky Web Studio - Capability Statement Canva Design Automation

**Purpose:** Browser-actionable prompts for Comet (Codeium) to automate Canva design tasks  
**Target:** Complete 8-page capability statement in Canva  
**Prerequisites:** Canva Business account, Rocky Web Studio logo file, content document ready

---

## HOW TO USE THESE PROMPTS

1. **Open Comet Browser Assistant** (Codeium extension in browser)
2. **Copy and paste** each prompt section into Comet
3. **Execute one section at a time** (wait for completion before next)
4. **Verify checkpoints** before proceeding to next section
5. **Adjust as needed** if Comet encounters UI differences

**Note:** Comet may need manual intervention for complex design tasks. Use these prompts as a guide and verify each step.

## TROUBLESHOOTING PROMPTS

### If Text is Too Small

```
Increase the font size of the problematic text to 16px minimum for body text. Increase heading sizes (H2 to 28px, H3 to 20px). Check contrast ratio using an online contrast checker. Ensure 4.5:1 minimum contrast on colored backgrounds.
```

### If Image Doesn't Fit

```
Resize the image to maximum 80% of page width (680px for 8.5" page). Center the image horizontally. Add 40px margin above and below the image. Maintain aspect ratio by holding Shift while resizing.
```

### If PDF is Too Large

```
Compress images before uploading to Canva. Re-export the PDF as "PDF - Standard" instead of "PDF - Print" for smaller file size. Reduce the number of images. Use lower resolution images (still readable, but smaller file).
```

### If Download Link Doesn't Work

```
Verify the file path is exactly: /public/Capability-Statement-Gov-Enterprise.pdf. Check the file name matches exactly (case-sensitive: Capability-Statement-Gov-Enterprise.pdf). Ensure the file is in the public folder (not public/pdfs/ or other subfolder). Test in an incognito window to clear cache. Check Vercel deployment logs for errors.
```

### If Colors Look Wrong

```
Verify hex codes are correct: #218092 for teal, #fcfcf9 for cream, #1f2121 for dark. Check color mode is RGB for digital (not CMYK). Test on different screens/devices. Re-export with "High" quality setting.
```

### If Spacing Looks Inconsistent

```
Use Canva's alignment guides (View → Show guides). Set guides to 40px from edges. Use alignment tools (not manual positioning). Check measurements using the ruler or grid.
```
