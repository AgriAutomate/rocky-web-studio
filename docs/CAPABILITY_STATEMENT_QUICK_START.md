## TROUBLESHOOTING

### Q: "Text is too small/hard to read"
**A:** 
- Increase font size to **16px minimum** for body text
- Increase heading sizes (H2: 28px, H3: 20px)
- Check contrast ratio (use online contrast checker)
- Ensure 4.5:1 minimum contrast on colored backgrounds

### Q: "Image doesn't fit on page"
**A:**
- Resize image to **max 80% of page width** (680px for 8.5" page)
- Center image horizontally
- Add **40px margin** above and below image
- Maintain aspect ratio (hold Shift while resizing)

### Q: "PDF file is too large (>2MB)"
**A:**
- Compress images before uploading to Canva
- Re-export as **"PDF - Standard"** (smaller file size)
- Reduce number of images
- Use lower resolution images (still readable, but smaller file)

### Q: "Download link doesn't work (404 error)"
**A:**
- Verify file path is exactly: `/public/Capability-Statement-Gov-Enterprise.pdf`
- Check file name matches exactly (case-sensitive: `Capability-Statement-Gov-Enterprise.pdf`)
- Ensure file is in `public` folder (not `public/pdfs/` or other subfolder)
- Test in incognito window (clear cache)
- Check Vercel deployment logs for errors

### Q: "Colors look wrong in PDF"
**A:**
- Verify hex codes are correct (`#218092` for teal, `#fcfcf9` for cream)
- Check color mode (RGB for digital, not CMYK)
- Test on different screens/devices
- Re-export with "High" quality setting

### Q: "Spacing looks inconsistent"
**A:**
- Use Canva's alignment guides (View → Show guides)
- Set guides to **40px** from edges
- Use alignment tools (not manual positioning)
- Check measurements (use ruler or grid)

### Q: "Icons look different sizes"
**A:**
- Resize all icons to exact sizes: **24px, 32px, or 40px**
- Hold **Shift** while resizing (maintains proportions)
- Use same icon set throughout (Feather or Tabler)
- Group icon + text for consistency

### Q: "Can't find Canva Business access"
**A:**
- Sign up for Canva Business (free trial available)
- Or use Canva Pro (similar features)
- Or use free Canva (some limitations, but still works)
